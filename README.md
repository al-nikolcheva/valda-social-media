# VALDA social media

Public images, PDFs and videos for VALDA's LinkedIn and Instagram posts. Buffer downloads post media from here, so this repository must stay **public**.

- `posts/<post>/ig/` — Instagram carousel slides, in order
- `posts/<post>/li/` — LinkedIn document carousel (`carousel.pdf` + `cover.png`) or single `image.png`

Only finished, publishable media goes here. No website code, drafts or notes.
